Semáforo IRTRA Petapa

EL PROYECTO

Una solución que combina programación, electrónica y diseño para comunicar de forma clara el estado de acceso dentro de una fila.

01

Problemática

El proyecto parte de la necesidad de organizar mejor el flujo de personas en zonas de acceso y disminuir confusiones durante el ingreso, aportando una señal visual fácil de comprender.

02

Solución propuesta

El sistema utiliza una lógica de señalización tipo semáforo para transformar el estado de acceso en indicaciones visuales inmediatas. La propuesta integra un circuito automatizado, programación en C++ y una representación clara para el usuario.

03

Aplicación en IRTRA Petapa

La solución está planteada para un entorno de entretenimiento donde la claridad, el orden y la seguridad del visitante son importantes. El prototipo muestra cómo un sistema electrónico sencillo puede apoyar la experiencia operativa.

04

Desarrollo del prototipo

El trabajo reúne simulación digital, evidencia de implementación física, documentación formal, infografía ejecutiva, podcast y una landing page final como centro de entrega.
